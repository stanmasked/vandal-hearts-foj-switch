# Stage299 — consensus across multiple independent pixel witnesses

**Base:** [Stage298 Draft PR #183](https://github.com/stanmasked/vandal-hearts-foj-switch/pull/183). Stage298 already fails closed on a single ambiguous reference; Stage299 makes it possible for **several independently captured source/reference pairs** to jointly narrow the same eight invented layout hypotheses.

## Why this is needed

A solid non-gray image can distinguish red and blue ordering without disambiguating spatial tiling. A grayscale, position-dependent image can distinguish raster/Morton and tile width while remaining ambiguous between BGRA and RGBA. **These are different observations.** The intersection of their matching candidate sets can have exactly one result when each is ambiguous alone. Conversely, if all images are flat gray, *every* texture may be reversible under all eight layouts and we must refuse to assert a unique result.

## Local-only sources and manifest

Use **three to eight distinct** already-extracted source files, with **one independent trusted SHA-256** for each source and **one different independent expected canonical RGBA mip-chain SHA-256** for each sample. The expected RGBA reference must be captured by a separately validated method, **not generated by the same conjectural interpretation**. The source, source digest, reference digest and manifest directories must be separate and not nested; none may traverse symlinks. Each digest and manifest is mode 0600, owner-only. Do **not** include any of this in GitHub, CI, discussions or attachments.

The owner-local manifest is a tiny JSON document with this exact schema. Values below are illustrative *local relative filenames*, never original resource identifiers:

```json
{
  "schema": "foj.stage299.owner_local_cases.v1",
  "cases": [
    {"source": "example-a.bin", "source_digest": "source-a.sha256", "reference_digest": "rgba-a.sha256"},
    {"source": "example-b.bin", "source_digest": "source-b.sha256", "reference_digest": "rgba-b.sha256"},
    {"source": "example-c.bin", "source_digest": "source-c.sha256", "reference_digest": "rgba-c.sha256"}
  ]
}
```

```bash
python3 -m tools.foj_stage299_private_multi_witness_consensus \
  --source-root /PRIVATE/EXTRACTED \
  --source-digest-root /PRIVATE/SOURCE-DIGESTS \
  --reference-digest-root /PRIVATE/INDEPENDENT-RGBA-DIGESTS \
  --manifest-root /PRIVATE/MANIFEST \
  --manifest-file witness-cases.json
```

The module independently verifies each original file using two bounded SHA-256 passes and a third verified read from its anchored no-symlink fd; all files are <= 2 MiB. The private manifest and digest files are separately anchored, double-read and checked for restrictive permissions. Identical source file **content** or identical reference hash across cases is rejected, even when filenames differ. No private strings, exact file sizes, source or witness hashes, pixels, paths or source bytes appear in the JSON response.

For each candidate, the module evaluates **all eight** Stage297 invented 4/8 tile, raster/Morton, RGBA/BGRA hypotheses and inverse-verifies every match. Each sample must match at least one. The intersection across **all** cases must be **exactly one**, or the entire check fails closed. The public-style local receipt contains the number of samples, number of individually ambiguous witnesses, and only the winning invented layout tuple. **No real source-derived conversion is enabled.**

## Limits and what counts as progress

Three different sources and expected RGBA hashes do not by themselves establish that the references are *independent*, that the same layout applies to all game assets, that any descriptor field is correct, or that the NPEB00148 image format is GTF. A unique result among eight invented hypotheses is **not** exhaustive knowledge of RSX formats. BCn/tiled variants, endian rules and materials remain unverified. Without actual privately accessible PS3 title resources and separately authenticated reference pixels, this stage establishes only synthetic algorithm behavior.

CI runs generated-only cases on Python 3.11 and 3.13, including: grayscale spatial images, solid-color images, mixed-alpha mip variants, mutually conflicting layouts, all-gray ambiguity, wrong digest, reused source/reference identity, invalid private manifest, permission and symlink refusal. No original PS3 assets, private reports or generated RGBA files are uploaded.

**Next evidence dependency:** obtain authorized actual NPEB00148 source bytes in a private environment plus independent reference pixels; do not substitute additional synthetic stages for proof that original textures have been identified.
