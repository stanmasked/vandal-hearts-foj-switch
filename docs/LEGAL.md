# Repository content and legal boundary

This is an independent educational/homebrew porting research project.

Store **only** independently developed code, synthetic test data,
documentation, tool configurations and technical findings without verbatim
commercial content.

Do not push any of:
- PS3 PKG files or split archives, disc images, game executables or extracted
  commercial game assets.
- PSN entitlement or activation files, RIF/RAP/EDAT, private keys, credentials,
  account secrets, or decryption material.
- Proprietary SDK files or copyrighted game code.

Game data remains local to the lawful owner. The research tools should
operate read-only by default and never upload data automatically.

Follow applicable copyright law, platform terms, and licenses. Possession of
a game copy does not by itself confer redistribution rights.

This project is **not affiliated** with Konami, Hijinx Studios, Sony or Nintendo.
No permission to release a bundled copy of the original game is assumed.
